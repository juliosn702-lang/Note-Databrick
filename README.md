# Nota-Databrick

## Descripción del proyecto

Este repositorio contiene el desarrollo del trabajo académico realizado para la asignatura relacionada con Databricks.

## Contenido

- `Notenook1.html`: archivo HTML exportado del notebook, que permite consultar el desarrollo del trabajo, el código y los resultados incluidos en la exportación.

## Cómo consultar el trabajo

1. Ingresa al archivo `Notenook1.html` desde la lista de archivos del repositorio.
2. Descarga el archivo para visualizarlo en un navegador web si GitHub no muestra su contenido directamente.
